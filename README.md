# Настройка и администрирование системы управления спортивными событиями с автоматической обработкой данных участников
Проект подразумевает собой веб-ресурс, созданный для спортивного фестиваля школы 2051.
На данный момент есть рабочий API.

## Интерфейс фестиваля

После запуска проекта страница доступна по адресу http://localhost:8080.

Файлы интерфейса находятся в `app/nginx`:

- `index.html` — главная страница.
- `events.html` и `event.html?discipline=running` — соревнования и описание выбранной дисциплины.
- `participants.html` и `participant.html?id=1` — список участников и карточка участника.
- `registration.html` — отдельная форма регистрации. Параметр `?discipline=running` заранее выбирает дисциплину.
- `style.css` — цвета, сетки, кнопки и адаптация под телефон.
- `app.js` — загрузка данных, поиск, фильтрация, регистрация и отмена регистрации.
- `assets/runners.jpg` — фотография с Unsplash; источник указан в `assets/SOURCES.md`.

Страница обращается к `/api/events` и `/api/participants`. Внешний Nginx
перенаправляет `/api/` на FastAPI, а остальные запросы — на frontend.
При регистрации JS отправляет POST с параметром `name`, как ожидает текущий API.
После регистрации появляется ссылка на созданную карточку участника. При переходе на список участников данные загружаются заново.

Интерфейс оформлен для спортивного фестиваля школы №2051 и является учебным макетом. Шахматы пока показаны
как планируемое соревнование; после добавления `chess` в таблицу `events`
появится обычная карточка с регистрацией. Нормативы медалей пока не утверждены.

После изменения HTML, CSS или JS пересоберите frontend:

```bash
docker compose up -d --build frontend
```

Если после пересоздания frontend прокси отвечает 502, обновите его подключения:

```bash
docker compose restart proxy
```

Панель отмены регистрации использует существующий DELETE API. Для итоговой
версии доступ организатора к этому действию нужно ограничить авторизацией.

Навигация между страницами выполнена обычными HTML-ссылками. Общий `app.js`
выбирает нужные функции по атрибуту `data-page` элемента `body`.
